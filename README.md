## 📌 Featured Projects

### 1. [SQL Data Warehouse & Analytics System](https://github.com/Friday-code254/SQL-Data-Warehouse-and-Analytics-System)

**Tech Stack:** SQL Server, T-SQL, Python, Docker, GitHub Actions

- Built a Bronze–Silver–Gold data warehouse integrating 116K+ sample ERP and CRM records into a star schema.
- Implemented SCD Type 2 to track historical changes and Python checks to validate input files and identify duplicate loads.
- Added an audit ledger for rejected sales records and automated testing through Docker and GitHub Actions.

### 2. [Credit Default Risk Prediction](https://github.com/Friday-code254/Home-Credit-Default-Risk)

**Tech Stack:** Python, Pandas, Scikit-learn, LightGBM

- Engineered 478 features from seven relational tables in the Home Credit dataset.
- Trained a LightGBM classifier on imbalanced data and evaluated it using stratified 5-fold cross-validation.
- Reported ROC-AUC of **0.783** and PR-AUC of **0.277** for the evaluated pipeline.

### 3. [Campus Compass — Document Question Answering](https://github.com/Friday-code254/Campus-Compass)

**Tech Stack:** Python, FastAPI, SQLite, TF-IDF, Information Retrieval

- Built a web application for searching campus handbooks in PDF, Markdown, and TXT formats.
- Implemented TF-IDF and cosine-similarity retrieval to find relevant document passages.
- Added source citations and evidence checks to handle questions when the available information is insufficient.

### 4. [Multimodal Video Sentiment Analysis](https://github.com/Friday-code254/Multimodal-Sentiment-Analysis-with-DLF)

**Tech Stack:** Python, PyTorch, Hugging Face Transformers, BERT
